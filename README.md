# Jonita Control

Sistema de gestión de ventas financiadas de teléfonos Android y seguimiento de cuotas.

## Objetivo

Administrar clientes, equipos vendidos, planes de pago, vencimientos, pagos y avisos de cuotas pendientes desde un panel privado.

## Alcance inicial

- Panel de administración de acceso privado.
- Registro de clientes y equipos (Motorola, Samsung, Xiaomi, TCL y otras marcas).
- Gestión de ventas financiadas y cuotas mensuales.
- Registro de pagos, vencimientos y estados de cuenta.
- Historial de avisos y acciones administrativas.
- Aplicación Android complementaria para los equipos, sujeta a consentimiento informado del comprador.

## Seguridad y cumplimiento

Cualquier restricción funcional del dispositivo deberá ser transparente, contar con autorización expresa e informada, cumplir las políticas de Android y la legislación aplicable, incluir avisos previos y un mecanismo de reclamo y restablecimiento al regularizar la deuda. La aplicación no realizará vigilancia oculta ni accederá a datos personales ajenos a su funcionamiento.

## Estado

Inicio del proyecto. La arquitectura, tecnologías y funcionalidades se definirán y documentarán antes de implementar cada módulo.
